Модулирование аттрактора системы Лоренца методом Рунге-Кутта 4 порядка с движением камеры (стрелки - по окружности, a w s d - относительно центра) 
с редактурой начального положения pos и параметров sigma, r, b

Запуск скрипта происходит командой: "g++ main.cpp -o lorenz.exe -lglfw3 -lglew32 -lopengl32 -lgdi32 -luser32 -lm" 
c предустановленными glew, glfm
